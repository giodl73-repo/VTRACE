## Integration

- ROLES: `.roles/ROLE.md` and `docs/vtrace/ROLE_RECOMMENDATIONS.md` assign
  review lenses for systems engineering, traceability, V&V, assurance, source
  custody, adoption guidance, maintainability, and future-agent continuity.
- VTRACE: this repo is the framework and self-trace reference; PITFALL entries
  cite local VTRACE requirements, evidence, validation, roles, source-custody,
  and CLI orchestration records rather than copying reusable doctrine into
  trace rows.
- Tests: Rust tests and CLI dry-runs are evidence only when they preserve
  deterministic validation, explicit live side-effect gates, advisory provider
  output, and objective evidence links.
